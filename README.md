# 特码盲区互补助手

线上：<https://whitworthbassalips894-crypto.github.io/Lottery-Simulator/>

本页与 [Number-selection-tool（工具2）](https://whitworthbassalips894-crypto.github.io/Number-selection-tool/) 配合使用。每期先计算工具2 的三组并集，本页的三个策略只在其余号码中各推荐 7 码，因此五个档位都与工具2 零重叠。

## 三策略评分与五档主推

| 策略 | 组内评分参考 |
|---|---|
| #1 正码传导 | 近期正码出现次数、30 期全奖频次、夹号及合 50 联动 |
| #2 中段蓄力 | 特码遗漏 16～30 期的号码、尾数和生肖频次 |
| #3 肖热透支 | 近 25 期活跃生肖、7～15 期浅冷及全奖遗漏 |

三组等权，只给自己推荐的号码加分。每次推荐给 **20 分**，再按该号码的组内原始得分排名给 **7～1 分**：第 1 名加 7 分，第 2 名加 6 分，以此类推。名次用「竞赛名次」：并列第一都加 7 分，下一名加 5 分（比较时留 1e-9 容差，避免浮点误差拆散同分号）。同号跨组累加，所以多组共同推荐的号码排在单组号码之前；总分相同按号码从小到大排列。

**5 / 7 / 10 / 12 码档**取总分排名的前 N 码；不足 N 码时不从组外补号。**第五档不是固定 18 码**：取 #1 传导 ∪ #2 蓄力 ∪ #3 肖热去重后的全部号码，按号码升序展示。按钮显示「并集全取 N码」，N 随当期实际数量变化。内置底库最近 1,700 期的并集为 12～21 码，平均约 16.4 码（无前序数据的首期为 7 码）。各档推荐号码下方标注所有推荐该号码的策略，不显示分数。复制时只保留两位号码，按升序用中文逗号分隔，如 `15，28，30`。

在「下期盲区主推」中点开 **三策略号码明细**，可以按策略查看目标期各自推荐的全部 7 个号码。多个策略推荐了同一号码，它会在每个对应组中出现。切换档位不会改变这三组；补录或同步开奖后，明细随目标期一起更新。

## 本期决策卡（首屏）

首屏第一张卡片就是「下期主推」，按用户当晚的真实动作排布：

- **期号 + 倒计时**：按北京时间 21:30 估算「还差多久开奖」；底库超过一天没更新会直接提示「已 N 天没有新开奖入账，请同步」。
- **覆盖成本**：`覆盖 K/49 码 = 命中率 K/49`、按 10 元/码的每期成本、48 倍赔率下的返奖率 **97.96%** 与每期期望净收益。命中率就是覆盖率，历史走势无法改变这个比例。
- **复制内容带上下文**：`2026-321｜10码｜02，08，10，…`，粘到微信或投注站也能看出是哪期、几码。
- **档位记忆**：上次选的档位会记在本机；键盘 ←/→ 可切档。

## 命中记录

- 首页简表按时间倒序列出最近 **30 期有效开奖**，切换档位即更新命中数，并同时给出**理论命中率**与 **95% 置信区间**，避免把 7/30 当成好成绩。
- 三策略命中率看板按最近 **200 期**统计，画 95% 区间；区间跨过随机基线 14.3% 时明确写「与随机不可区分」。
- 「查看全部」可看按年汇总和逐期明细。回放与下期主推使用同一套评分函数，每期只读取目标期之前的有效开奖。
- 锁定面板会汇总所有已核对的锁定记录：命中期数 / 总期数、按当时覆盖码数应得的理论值、95% 区间，直接回答「这段时间我的打法到底怎样」。
- 锁定保存的是所选档位当时的号码，开奖后按快照核对；旧锁定记录不会按新规则重算。

每期开奖独立随机。分数用于排序，不是中奖概率；历史命中仅作统计参考。

## 开发与部署

```bash
npm ci
npm start      # 本地预览：http://localhost:4173/
npm run check  # JSDOM 校验评分、档位、锁定与历史回放
```

GitHub Pages 直接发布 `main` 分支的 `docs/`，无需构建。页面、内置底库和主推引擎在 `docs/index.html`；`docs/src/note-sync.js` 负责一键同步，`docs/data/draws.json` 是仓库开奖数据源。「数据管理」支持手动补录、导入导出及撤销本机新增记录。补录框可以直接**整段粘贴开奖网站原文**：期号、日期、时间会被自动忽略，只取 7 个开奖号码；号码非法或重复会在格子下方逐条说明原因，而不是默默失败。
