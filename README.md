# 特码盲区互补助手

线上：<https://whitworthbassalips894-crypto.github.io/Lottery-Simulator/>

本页与 [Number-selection-tool（工具2）](https://whitworthbassalips894-crypto.github.io/Number-selection-tool/) 配合使用。每期先计算工具2 的三组并集，本页的三个策略只在其余号码中各推荐 7 码，因此五个档位都与工具2 零重叠。

## 三策略评分与五档主推

| 策略 | 组内评分参考 |
|---|---|
| #1 正码传导 | 近期正码出现次数、30 期全奖频次、夹号及合 50 联动 |
| #2 中段蓄力 | 特码遗漏 16～30 期的号码、尾数和生肖频次 |
| #3 肖热透支 | 近 25 期活跃生肖、7～15 期浅冷及全奖遗漏 |

三组等权，只给自己推荐的号码加分。每次推荐给 **20 分**，再按该号码的组内原始得分给 **1～7 分**：第一名加 7 分，第二名加 6 分，以此类推。并列按同一名次给分（如并列第一都加 7 分，下一名加 5 分）。同号跨组累加，所以多组共同推荐的号码排在单组号码之前；总分相同按号码从小到大排列。

**5 / 7 / 10 / 12 码档**取总分排名的前 N 码；不足 N 码时不从组外补号。**第五档不是固定 18 码**：取 #1 传导 ∪ #2 蓄力 ∪ #3 肖热去重后的全部号码，按号码升序展示。按钮显示「并集全取 N码」，N 随当期实际数量变化。内置底库最近 1,700 期的并集为 12～21 码，平均约 16.4 码（无前序数据的首期为 7 码）。各档复制文本均为两位数字，按升序用英文逗号分隔。

## 命中记录

- 首页简表按时间倒序列出最近 **30 期有效开奖**，切换档位即更新命中数。温度计仍按三个单组各自统计。
- 「查看全部」可看按年汇总和逐期明细。回放与下期主推使用同一套评分函数，每期只读取目标期之前的有效开奖。
- 锁定保存的是所选档位当时的号码，开奖后按快照核对；旧锁定记录不会按新规则重算。

每期开奖独立随机。分数用于排序，不是中奖概率；历史命中仅作统计参考。

## 开发与部署

```bash
npm ci
npm start      # 本地预览：http://localhost:4173/
npm run check  # JSDOM 校验评分、档位、锁定与历史回放
```

GitHub Pages 直接发布 `main` 分支的 `docs/`，无需构建。页面、内置底库和主推引擎在 `docs/index.html`；`docs/src/note-sync.js` 负责一键同步，`docs/data/draws.json` 是仓库开奖数据源。「数据管理」支持手动补录、导入导出及撤销本机新增记录。
